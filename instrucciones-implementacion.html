Instrucciones para Implementar la Corrección de Enlaces

Para solucionar el problema de los enlaces del footer que no funcionan correctamente desde diferentes páginas, hay dos opciones de implementación:

Opción 1: Incluir el script fix-links.js en todas las páginas

Esta es la opción más sencilla y recomendada:

  1. Guarda el archivo fix-links.js en la carpeta raíz del proyecto.
  2. Añade la siguiente línea justo antes del cierre de la etiqueta </body> en todas las páginas HTML:
<script src="/fix-links.js"></script>

Nota: Si tienes un sistema para incluir scripts en todas las páginas (como el include-components.js), puedes añadir este script allí para que se cargue automáticamente.

Opción 2: Modificar el archivo include-components.js

Si prefieres modificar directamente el archivo include-components.js:

  1. Abre el archivo include-components.js
  2. Busca la función setupFooterFunctionality()
  3. Añade el siguiente código al principio de esta función:
// Corregir enlaces del footer
const footerLinks = document.querySelectorAll("footer a");
footerLinks.forEach(link => {
  const linkText = link.textContent.trim();
  const href = link.getAttribute("href");
  
  // Si el enlace ya tiene una ruta absoluta o comienza con http, no lo modificamos
  if (href && (href.startsWith("/") || href.startsWith("http"))) {
    return;
  }
  
  // Determinar la ruta correcta según el texto del enlace
  let newHref = "";
  
  // Sobre Nosotros
  if (linkText === "Quiénes Somos" || linkText === "Qui Som") {
    newHref = pathToRoot + "US1_PantallaInicio/quienes-somos.html";
  } else if (linkText === "Contacto" || linkText === "Contacte") {
    newHref = pathToRoot + "US1_PantallaInicio/contacto.html";
  }
  // Legal
  else if (linkText === "Política de Privacidad" || linkText === "Política de Privacitat") {
    newHref = pathToRoot + "US1_PantallaInicio/politica_privacidad.html";
  } else if (linkText === "Términos y Condiciones" || linkText === "Termes i Condicions") {
    newHref = pathToRoot + "US1_PantallaInicio/terminos_condiciones.html";
  } else if (linkText === "Política de Cookies") {
    newHref = pathToRoot + "US1_PantallaInicio/politica_cookies.html";
  } else if (linkText === "Aviso Legal" || linkText === "Avís Legal") {
    newHref = pathToRoot + "US1_PantallaInicio/aviso_legal.html";
  }
  // Comunidad
  else if (linkText === "Recetas" || linkText === "Receptes") {
    newHref = pathToRoot + "Platos.html";
  } else if (linkText === "Chefs" || linkText === "Xefs") {
    newHref = pathToRoot + "US1_PantallaInicio/chefs.html";
  }
  
  // Actualizar el enlace si hemos encontrado una correspondencia
  if (newHref) {
    link.href = newHref;
    console.log(`Enlace "${linkText}" actualizado a: ${newHref}`);
  }
});

Importante: Asegúrate de que la variable pathToRoot esté correctamente definida antes de usar este código. Esta variable ya debería estar disponible en el contexto de la función setupFooterFunctionality().

Verificación

Para verificar que los enlaces funcionan correctamente:

  1. Abre la consola del navegador (F12)
  2. Navega a diferentes páginas del sitio
  3. Verifica que en la consola aparezcan mensajes indicando que los enlaces se han actualizado
  4. Haz clic en los enlaces del footer y comprueba que te llevan a las páginas correctas

Si sigues teniendo problemas, revisa la consola del navegador para ver si hay errores y asegúrate de que las rutas a los archivos son correctas.
