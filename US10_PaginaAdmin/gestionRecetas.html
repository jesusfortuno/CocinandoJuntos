Instrucciones para Generar Páginas HTML de Recetas

Este sistema te permite generar automáticamente archivos HTML para tus recetas con la estructura correcta para tu sitio web.

  1. Añade o edita una receta usando el formulario.
  2. Después de guardar la receta, se te preguntará si deseas generar el archivo HTML inmediatamente.
  3. También puedes generar el HTML en cualquier momento haciendo clic en el botón "Generar HTML" en la tabla de recetas.
  4. El archivo HTML se descargará automáticamente a tu ordenador.
  5. Debes guardar manualmente el archivo descargado en la carpeta "US6_GuardarRecetas" de tu proyecto.
  6. El archivo HTML tendrá la misma estructura que el ejemplo de "pollo-agridulce.html".
